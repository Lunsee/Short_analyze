# Отчет об оплате работ по договорам

Тестовое задание "аванс по договору". Программа по выгрузке договоров, работ и платежей строит отчет на дату:

- по каждой работе: цена, сколько выплачено, сколько осталось оплатить;
- по каждому договору: итоги, долг за уже принятые работы, переплата, платежи в очереди.

Деньги считаются в `Decimal` до копейки, без float.

## Как запустить

Нужен Python 3.10+, внешних зависимостей нет.

Данные в репозиторий не входят. Положите папку `data/` с файлами `contracts.csv`, `works.csv`, `payments.csv` рядом с `report.py`:

```
report.py
test_report.py
data/
  contracts.csv
  works.csv
  payments.csv
```

Команды выполняются из папки с `report.py`:

```
python report.py --date 2026-11-10                      # отчет в консоль (можно и --date 10.11.2026)
python report.py --date 2026-11-10 --csv report.csv     # дополнительно CSV для Excel (разделитель ;)
python report.py --data path/to/data --date 2026-11-10  # другая папка с данными
python -m unittest test_report.py                       # тесты (нужна папка data/ с исходными данными)
```

Дата отчета включительная: события с этой датой уже учитываются.

## Файлы

- `report.py` - программа;
- `test_report.py` - тесты;
- `DECISIONS.md` - решения и допущения, принятые по ходу работы;
- `ЗАПИСКА_БУХГАЛТЕРУ.md` - как читать отчет и что нужно подтвердить;
- транскрипт работы с Claude Code - экспорт `/export`.

## Что не сделано и что дальше

- Частичные возвраты и несколько валют не поддержаны: в формате данных их нет.
- Порядок разнесения платежей без привязки к работе зашит в код (см. `DECISIONS.md`, решение 4). Если бухгалтер выберет другой, его стоит вынести в параметр.
- Тесты проверяют реальные данные на нескольких датах. Стоит добавить синтетические случаи: платеж на отмененную работу, неизвестный договор и т. п.
